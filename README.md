# 造游星球课程切片原型

这是一个无依赖的静态网页原型。当前优先验证两节完整课：`L1-08 状态小关` 和面向 14 岁学生的 `L2-18 验证 AI，而不是盲信 AI`。L0-L2 课程天梯暂作为路线图保留。

## 运行方式

直接用浏览器打开 `state-lab.html` 可体验 L1 状态课。
直接用浏览器打开 `ai-verify-lab.html` 可体验 L2 AI 验证课。
也可以打开 `index.html` 查看路线图入口。

## 当前包含

- `state-lab.html`：L1-08 钥匙门机关房 vertical slice。
- 完整课流程：观察、预测、拼规则、修错诊断、迁移挑战、证据卡。
- 规则卡片拼装：支持多条 `当 / 如果 / 就` 规则和干扰项。
- 状态面板：实时显示 `hasKey`、`doorOpen`、`hp` 并高亮变化。
- 必经 debug：拿到钥匙后门仍不开，学生需要修复门规则条件。
- 状态时间线：记录从开始、观察、拿钥匙、开门、碰危险到完成的状态变化。
- 证据卡：通关后保存状态链路、bug 修复和一句复盘到 `localStorage`。
- `ai-verify-lab.html`：L2-18 AI 建议验证课，包含可玩的护盾竞技场、读需求、预测测试、运行测试、审查 AI、选择补丁、补测试和证据卡。
- `report.html`：读取本地证据卡，生成家长可见成果摘要。
- `index.html`：保留 L0-L2 课程路线图，并提供 L1/L2 两个课程入口。
