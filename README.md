# Signal Runner Node

当前主项目是 `signal-runner-node`：一个面向 14 岁学生的独立 3D 闯关式编程作品节点原型。

## 打开方式

直接用 Edge / Chrome 打开：

```text
signal-runner-node/index.html
```

也可以打开根目录的 `index.html`，它会自动跳转到 Signal Runner。

## 当前保留

- `signal-runner-node/`：主项目，包含 6 节课作品节点、3D 小岛场景、指令编排、运行日志和作品卡。
- `archive/legacy-course-platform/`：旧 L0/L1/L2 静态课程门户、旧实验课页面和历史 PRD，仅作归档参考。

## 方向

后续开发以 Signal Runner 为主，不再继续扩展旧课程门户。
