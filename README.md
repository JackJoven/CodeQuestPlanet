# AI 游戏规则编程课原型

这是一个无依赖的静态网页 MVP，用来验证前 2 关：

> 第 1 关：控制校准场，把“按键事件”连接到“移动动作”。
> 第 2 关：分数晶核，把“收集事件”连接到 `score` 变量。

## 运行方式

直接用浏览器打开 `index.html` 即可。

## 当前包含

- 两关任务切换：控制校准场、分数晶核。
- 两条学生自选路线：星际射击、平台跳跃。
- 可运行的小游戏画布，支持 `WASD` 和方向键。
- “坏掉的游戏 -> 修复规则 -> 代码透视 -> AI 伴学复盘”的学习闭环。
- 规则编辑器原型：`当 / 如果 / 就`。
- 代码透视眼：中文规则、伪代码、Python 三种显示。
- AI 伴学面板：提示、解释、调试和复盘的模拟交互。
- 第 2 关包含 `score` 分数、目标、已收集数量和阶段 1 评价出口。
