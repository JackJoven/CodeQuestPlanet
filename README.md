# 造游星球课程天梯原型

这是一个无依赖的静态网页原型，用来展示 `L0-L2` 前三学段的课程天梯、课程任务页和作品沉淀入口。

## 运行方式

直接用浏览器打开 `index.html` 即可。

## 当前包含

- `L0-L2` 三个学段的课程地图与任务入口。
- 按渐进式路径设计的 `12 + 16 + 24 = 52` 节课程数据。
- 课程任务页：课程选择、自学任务单、规则编辑器、代码透视和 AI 伴学面板。
- 示例任务舱原型：保留了早期可运行玩法，用来承载任务页交互。
- 作品工坊、成长报告等课程平台外壳页面。
