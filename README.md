# AI 游戏规则编程课原型

这是一个无依赖的静态网页 MVP，用来验证第 1 课：

> 控制我的角色：把“按键事件”连接到“移动动作”。

## 运行方式

直接用浏览器打开 `index.html` 即可。

## 当前包含

- 两条学生自选路线：星际射击、平台跳跃。
- 可运行的小游戏画布，支持 `WASD` 和方向键。
- “坏掉的游戏 -> 修复规则 -> 代码透视 -> AI 伴学复盘”的一课闭环。
- 规则编辑器原型：`当 / 如果 / 就`。
- 代码透视眼：中文规则、伪代码、Python 三种显示。
- AI 伴学面板：提示、解释、调试和复盘的模拟交互。
