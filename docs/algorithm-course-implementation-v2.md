# 算法课程 33–48：实施说明（v2.0）

## 定位

这 16 节课直接接在原项目第 32 课后，分属「算法工坊」和「搜索与策略」两章。目标是让 10–14 岁学生能解释、选择并验证算法，而不是把地图动画当成算法本身。16 节课足以做出可解释的路线规划器，但不等于完整的竞赛算法体系；约 60 分钟课时与学生独立迁移效果仍需试教。

## 地图与算法的关系

地图是问题空间和结果空间；算法观察窗是内部状态的放大镜。33–36 课以数据轨道解释算法，3D 世界把每个数据项标成货舱；37–44、48 课把地形直接作为图，并在 3D 地图上标出当前、待处理、已发现和最终路线；45–46 课用补给站坐标表达路线选择；47 课用依赖分叉表达重复子问题。16 节课的基础地形轮廓均不同，换题还会镜像或增添支路。地图不承担排序交换、缓存等概念的全部解释，避免学生只看 Nova 移动而误以为理解了算法。

## 按《Hello 算法》重排讲解

每课的教学顺序统一为：具体问题与输入 → 两步直觉图解 → 适用前提或反例 → 学生选择规则 → 真实 Python 逐步运行 → 回看、解释代码与结果。学生不再一进课就面对「前沿容器」「前驱」等抽象选项；这些词出现在有了问题场景之后。第 47 课直接从书里的爬楼梯问题切入，明确第 0 阶的起始情况，再进入 `ways(n)` 与记忆化。

对应关系不是逐页搬运：33、36 对应第 10 章查找；35 对应第 11 章冒泡排序；37–42 主要对应第 9 章图与搜索；45–46 对应第 15 章贪心与反例；47 对应第 14 章动态规划。34 的安全筛选、40/42 的实际行走验证、43 的带权最短路、44 的调试和 48 的综合项目，都是为 CodeQuestPlanet 场景设计的应用或延伸题，不应称作书中的原练习。课程顺序为了衔接现有 1–32 课，未严格照搬书的目录顺序。

## 借鉴 VisuAlgo 的可视化方式

观察窗现在把一次算法「单步」定位到可观察的变化，而非 Python 初始化变量；它同步显示当前高亮、待处理队列/栈或候选集合、中文解释和相应代码行。学生可暂停后回看上一步、下一步、首步或最新一步，自动播放提供 1×、2×、4× 速度。回看只改变讲解窗，不会倒转 3D 世界、重新执行 Python 或重复授予通关证据。第 47 课用台阶与各阶走法数表达问题，再把重复依赖放在可展开的补充图中。这里借鉴的是「状态与解释同步」的交互方法，不复制 VisuAlgo 的源码、图形或文案。

## 验证与未解决问题

- 程序由学生选择的规则生成，按真实 Python 逐步执行；观察窗和 3D 地图都读同一批运行事件。
- 每课至少有引导题和语义变化的换题题目。强提示可以帮助完成任务，但不能替代独立迁移证据。
- 自动检查覆盖 16 课的两阶段、典型错误选项、真实最短路/最低能耗、真实贪心反例、16 种不同地图轮廓；第 1–32 课回归检查保持通过。
- 仍需对第 33、36、41、45、48 课做学生试教，重点记录首次有效操作、错误解释、提示使用与约 60 分钟内的独立迁移。自动测试不能证明教学效果。
