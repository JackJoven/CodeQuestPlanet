# 产品需求文档 v1.5：CodeQuestPlanet iCode × Swift Playgrounds 融合课程体系

**状态**：正式优化版  
**日期**：2026-07-15  
**替代版本**：v1.4  
**适用对象**：10-14 岁零基础或有图形化编程基础的学生  
**标准课时**：每课 60-90 分钟；校内 40-45 分钟课时可拆成两次

## 1. 版本结论（v1.5 核心升级）

v1.5 在 v1.4 的坚实知识与教学骨架上，全面升级**沉浸感、社交创作生态与游戏化成长系统**，目标是让学生“玩得停不下来、学得记得住、创得有成就感”。

```text
32 节共同核心（星际远征主线）
+ 16 节算法探索分支
+ 16 节互动创作分支
= 64 节完整课程库
```

**学生通常完成 48 节**：32 节共同核心 + 一个 16 节分支。  
也可选择 8 节算法 + 8 节创作的均衡路线。  
能力较强、课时充足的学生可完成全部 64 节。

### v1.5 新增三大支柱（决定爆火的关键）

1. **持续活着的星际世界**（Immersive Persistent World）  
   学生角色拥有持续成长的个人星舰与基地，32 节共同核心构成完整远征剧情，关卡与作品可永久留存并被他人游玩。

2. **创作所有权 + 社交社区**（Ownership & Social Ecosystem）  
   公开作品广场、Remix 机制、赛季挑战、多人协作、全球/班级排行榜，让学生从“解题者”变成“世界的创造者与分享者”。

3. **深度游戏化成长系统**（Deep Gamification）  
   XP、技能树、等级、连胜、失败图鉴、性能对比、每日/每周挑战，失败也变得有趣且有收获。

这些升级在保留 v1.4 全部知识优势与教学闭环的基础上，大幅提升留存率、口碑传播与学习动力。

## 4. 产品定位（v1.5 升级）

**CodeQuestPlanet** 是一套以**持续活着的 3D 星际远征世界**为主场景的编程思维与创作课程。

学生先控制角色和工具解决地图问题，再学习用数据描述世界、用算法规划行为、用事件和组件创建互动作品，最终把自己的创造发布到公共星图，让其他学生游玩、Remix 与评价。

课程不是 Swift Playgrounds 的复刻，也不是 iCode 地图的搬运。它使用原创角色、世界、关卡、文本和代码接口，吸收两者已验证的知识顺序与反馈机制，并加入**持久世界、创作所有权与深度游戏化**。

### 完成共同核心后，学生应能：

1. 预测程序执行结果并用证据调试。
2. 使用顺序、函数、循环、条件、变量和数据容器组织程序。
3. 理解类型、实例、属性、方法、参数和返回值。
4. 用数据描述地图、对象、目标和规则。
5. 设计可运行、可测试、可解释的原创关卡，并发布到公共星图。
6. 在持续世界中管理自己的星舰与基地，理解“代码即世界规则”。

完成算法分支后，学生应能用搜索、排序、图和路径算法解决任务，并比较算法取舍，形成“自动路线规划器”作品。

完成创作分支后，学生应能使用坐标图形、事件、状态、声音和组件完成互动故事、游戏或工具作品，并获得真实的用户反馈与 Remix 次数。

## 6. 单节标准课结构（v1.5 增强）

每节课不是一个知识点，而是一个完整任务包 + 世界成长节点。建议包含 5-8 个页面或挑战单元：

| 环节 | 建议时间 | 页面/挑战作用 | v1.5 新增 |
|---|---:|---|---|
| 剧情与概念导入 | 5-8 分钟 | 用现实类比或动画说明为什么需要新概念 | 远征主线剧情推进 + 星舰状态更新 |
| 观察与预测 | 8-12 分钟 | 标记地图、状态和目标，先写预测 | 世界日志与历史回放 |
| 引导挑战 | 10-15 分钟 | 只变化一个因素，建立正确操作 | 获得 XP 与模块碎片 |
| 迁移挑战 | 15-20 分钟 | 换地图或条件，不照抄上一题 | 性能对比（步数/能量/代码长度） |
| 调试挑战 | 10-15 分钟 | 阅读错误程序、日志或状态并修复 | 失败图鉴收集 + 调试徽章 |
| 开放挑战 | 10-20 分钟 | 比较方案、优化或补全作品 | 可选发布到公共星图（部分关卡） |
| 复盘与作品卡 | 5-10 分钟 | 记录策略、失败、修改和证据 | 自动生成成长雷达 + 语音讲解录制 |
| 世界结算（新增） | 3-5 分钟 | 星舰升级、资源结算、技能树点亮 | 每日/每周挑战入口 |

统一学习闭环（v1.5 升级版）：

```text
接收任务（主线剧情）
-> 侦察环境（世界状态）
-> 预测方案
-> 编写程序
-> 运行/单步/时间旅行调试
-> 阅读状态和失败证据
-> 修改与重构
-> 迁移或创作
-> 讲解与保存作品
-> 世界结算（XP / 技能 / 发布 / 排行）
```

## 7. 共同核心：32 节完整课程（主线远征）

### 7.0 课程结构总览（v1.5）

```text
共同核心 32 节 = 4 个星系章节（每章 8 节）
├── 第一章（1-8）：启动远征 —— 执行、空间与调试
├── 第二章（9-16）：危机应对 —— 函数与控制结构
├── 第三章（17-24）：数据驱动远征 —— 状态、类型与数据容器
└── 第四章（25-32）：重建星系 —— 世界建模与多对象系统

完成后学生获得：
- 个人星舰满级
- 个人基地
- 公共星图发布权限
- 共同核心毕业包 + 个人星际档案
```

分支选择（学生完成 32 节后）：
- 算法路线：+ A01–A16 → 自动路线规划器 + 算法技能树
- 创作路线：+ B01–B16 → 原创互动作品 + 创作技能树
- 均衡路线：两分支各选 8 节
- 完整路线：全部 64 节

### 主线剧情概览（v1.5 新增）
学生扮演“星际探索员”，从启动信号开始，逐步重建失落的 CodeQuestPlanet 星系。  
每 8 课为一个“星系章节”，完成后解锁新星域与星舰升级。  
所有学生共享同一个大世界，但拥有独立的个人星舰与基地。

## 13. 学生产出与评价（v1.5 升级）

每节作品卡至少包含：目标、预测、程序、第一次失败、失败证据、修改、最终结果、可优化点、**本课获得的 XP 与技能点**。

每 8 课阶段作品增加：回放或截图、测试用例、策略比较、同伴反馈、口头讲解、**发布数据（试玩次数、Remix 次数、评分）**。

### 建议总评（调整权重）

| 维度 | 权重 | 关注点 |
|---|---:|---|
| 任务完成 | 25% | 能满足目标和限制，不只偶然跑通 |
| 调试证据 | 20% | 能定位现象、原因、修改和结果 |
| 思路解释 | 15% | 能说明选择、状态和算法理由 |
| 创作与迁移 | 20% | 能修改规则、设计变式或原创作品 + 发布与 Remix |
| 协作与反馈 | 10% | 能轮换角色、阅读他人代码并给出建议 |
| 世界成长与社区贡献 | 10% | 星舰升级、公共星图贡献、帮助他人 |

小队角色继续使用舰长、导航员、工程师、调试官和讲解员，但每节必须轮换，并支持跨课长期小队。

## 18. 验收标准（v1.5 升级）

### 课程验收
1. 32 节共同核心和两个 16 节分支均有明确任务、知识、产出和能力门。
2. iCode 公开显式知识点全部进入共同核心或算法分支。
3. Swift Playgrounds 的类型/初始化、数组重构、世界建造、事件和创作链路均有对应课程。
4. 每节包含引导、迁移、调试和开放任务，不以单个微知识点充当整节课。
5. 每 8 节形成可保存、可试玩、可讲解的阶段作品。
6. **新增**：主线剧情完整连贯，学生有持续成长的星舰与基地。
7. **新增**：至少 30% 的创作关卡支持发布与 Remix。

### 产品验收
1. 课程数据、地图数据和运行逻辑分离。
2. 调试系统能展示状态变化和结构化失败证据 + 时间旅行。
3. 学生能从积木逐步迁移到文本代码。
4. 共同核心完成后，算法和创作分支都能独立运行。
5. 学生原创关卡或互动作品可保存、校验、试玩和评价。
6. **新增**：公共星图可用，支持试玩、评价、Remix。
7. **新增**：XP、技能树、失败图鉴、性能对比完整闭环。
8. **新增**：AI 助教提供 Socratic 引导而不直接给答案。
9. **新增**：学生成长档案可一键导出。
