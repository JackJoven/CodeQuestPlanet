# CodeQuestPlanet 前 32 节课程项目介绍

## 基本设定

- 形式：瑞士国际主义风横向网页 PPT，单 HTML 文件
- 受众假设：家长、教师、课程合作方与项目合作伙伴
- 演讲时长：约 20 分钟
- 主题：IKB 克莱因蓝，整套只使用一个强调色
- 重点：32 节共同核心课程；算法 16 节与互动创作 16 节只用一页带过
- 图片：使用项目现有世界地图与四章星球视觉，保真展示

## 叙事弧

1. Hook：编程不是在答题，而是在改变一个世界。
2. Context：解释 CodeQuestPlanet 是课程、可运行世界与学习证据系统的结合。
3. Core：展开 32 节、四章、每章八课的能力递进。
4. Learning Loop：说明学生如何观察、预测、编程、运行、调试、解释与创作。
5. Outcome：展示学生从执行指令到搭建多对象世界的能力跃迁。
6. Extension：一页提及算法探索 16 节与互动创作 16 节。
7. Closing：让学生从玩家成长为工程师，再成为世界的创造者。
