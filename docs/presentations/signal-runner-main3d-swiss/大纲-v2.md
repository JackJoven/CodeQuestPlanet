# CodeQuestPlanet 3D 主项目介绍

## 基本设定

- 形式：瑞士国际主义风横向网页 PPT
- 主题：IKB 克莱因蓝，整套只使用一个强调色
- 页数：12 页
- 演讲时长：8–10 分钟
- 内容边界：只讲当前 3D 主项目能够现场演示的学习闭环；不把 48 节入口包装成已经成熟的完整课程
- 图片策略：课程地图、阶段入口和 3D 编程界面全部使用主项目真实截图，保真展示

## 核心叙事

1. 这是一个可以运行的 3D 编程学习原型。
2. 学生从课程入口进入具体任务，在同一界面观察、编程、运行和调试。
3. 一条指令对应世界里一次可见变化；一次失败对应一条可解释日志。
4. 当前引擎已经支持序列、路径、条件、循环、函数和综合任务。
5. 已完成的能力与仍在完善的部分分开说明，保持项目介绍真实可信。

## 不在本版中重点宣传
