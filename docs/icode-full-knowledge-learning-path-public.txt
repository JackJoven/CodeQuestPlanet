二、这些关卡整体是在训练什么
----------------------------
公开游戏说明显示：学生需要用代码控制机器人 Neo 在太空地图中移动和转向，收集分布在地图上的能量；部分关卡还会使用飞板、飞船等工具帮助 Neo 完成任务。
从教学角度看，关卡训练的不是单纯记指令，而是完整的问题解决流程：观察地图、抽象规则、规划路线、写出程序、运行验证、根据反馈调试、优化表达。
这类任务很适合小学高年级到初中阶段做编程启蒙，也适合把图形化编程逐步迁移到 Python/C++ 的语法学习。

三、公开显式知识点逐项详解
--------------------------

knowledge_1: Moving Forwards / 向前移动
- 含义：让学生理解角色会沿着当前朝向前进一步，动作结果取决于“方向”和“位置”。
- 学生能学到：方向感、一步一格、执行结果预测、把自然语言动作转成代码指令。
- 掌握表现：学生能在运行前说出 Neo 前进后会到达哪一格。

knowledge_2: Moving Backwards / 向后移动
- 含义：让学生理解后退不是掉头，而是在保持当前朝向的情况下向反方向移动。
- 学生能学到：相对运动、当前朝向、正向/反向动作的区别。
- 掌握表现：学生能解释“后退一步”和“转身再前进一步”的不同。

knowledge_3: Changing Direction / 改变方向
- 含义：让学生理解转向会改变后续前进/后退的效果，但转向本身通常不改变位置。
- 学生能学到：方向状态、左转右转、连续转向、先转向后移动。
- 掌握表现：学生能用箭头标记每一步后的朝向。

knowledge_4: Order of Coding Commands / 代码指令顺序
- 含义：让学生理解程序按从上到下的顺序执行，调换两行代码可能得到完全不同路线。
- 学生能学到：顺序执行、程序流程、步骤分解、动作序列。
- 掌握表现：学生能比较两段同样指令但顺序不同的代码，并预测差异。

knowledge_6: For Loop/Statement / for 循环/循环语句
- 含义：让学生把重复动作抽象成“重复执行 N 次”，减少机械复制代码。
- 学生能学到：重复规律、循环次数、循环体、代码简化。
- 掌握表现：学生能把“前进、前进、前进、前进”改成循环。

knowledge_7: For Loop Indentation / for 循环缩进
- 含义：让学生理解缩进决定哪些语句属于循环体，缩进错误会改变程序行为。
- 学生能学到：代码块、层级结构、循环体边界、Python 语法习惯。
- 掌握表现：学生能指出哪些语句会被循环执行，哪些只执行一次。

knowledge_8: 列表 / 列表
- 含义：让学生用一个有顺序的容器保存多个数据，比如坐标、路线点、能量点。
- 学生能学到：集合式思维、顺序访问、索引、遍历准备。
- 掌握表现：学生能把多个目标点整理成一个列表并依次处理。

knowledge_9: 函数的参数 / 函数的参数
- 含义：让学生把可变化的信息传给函数，让同一个函数解决相似但不完全相同的问题。
- 学生能学到：抽象、输入、复用、参数名和实参。
- 掌握表现：学生能设计一个带“步数”或“方向”参数的路线函数。

knowledge_10: 函数的返回值 / 函数的返回值
- 含义：让学生理解函数可以计算或判断后把结果交回主程序继续使用。
- 学生能学到：输出、结果复用、判断函数、计算函数。
- 掌握表现：学生能写出或解释一个返回坐标、状态或布尔结果的函数。

knowledge_11: 字典 / 字典
- 含义：让学生用键值对保存对象状态，如对象名称到坐标、颜色到策略、方向到动作。
- 学生能学到：键值映射、按名称查找、结构化记录、状态表。
- 掌握表现：学生能用字典表达不同物品或角色的属性。

knowledge_12: while语句 / while 语句
- 含义：让学生理解“只要条件成立就继续”，适合不知道确切重复次数的任务。
- 学生能学到：条件循环、终止条件、避免死循环、状态变化。
- 掌握表现：学生能说清楚 while 循环什么时候继续、什么时候停止。

knowledge_13: 类 / 类
- 含义：让学生初步理解把数据和行为组合成对象，例如 Neo、Spaceship、Flyer 都有位置和动作。
- 学生能学到：对象、属性、方法、同类对象的共性。
- 掌握表现：学生能用“对象有属性和方法”的语言描述一个游戏角色。

knowledge_14: 逻辑运算符 / 逻辑运算符
- 含义：让学生组合多个判断条件，例如“前方可走并且还有能量”或“不是红色能量”。
- 学生能学到：and/or/not、复合条件、布尔表达式、条件策略。
- 掌握表现：学生能把两个简单判断合成一个完整判断。

knowledge_15: 注释 / 注释
- 含义：让学生用自然语言说明代码意图，帮助自己和同伴读懂解法。
- 学生能学到：代码可读性、解释思路、标注关键步骤、沟通表达。
- 掌握表现：学生能为一段路线代码写出简短清楚的注释。

knowledge_16: 修改变量的值 / 修改变量的值
- 含义：让学生理解变量会随着程序运行发生变化，可用于计数、记录能量或更新当前位置。
- 学生能学到：赋值、更新、计数器、状态追踪。
- 掌握表现：学生能解释 count = count + 1 这类更新语句的作用。
