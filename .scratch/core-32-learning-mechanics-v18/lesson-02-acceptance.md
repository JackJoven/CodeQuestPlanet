# 第 2 课验收：相对方向

内容版本：`1.8-02.1`。日期：2026-09-20。未提交、未部署。

## 已实现

- 学生从空程序开始，继续使用原卡片编排前进、左转、右转和采集；转向和移动分别映射到真实 Python 事件。
- 两阶段为“读懂角色左右 / 朝向与镜头迁移”。同高十字桥形成四向岔台，错误左右会进入真实错误支路。
- 引导从朝东出发，在岔台右转；迁移改为朝北出发，在同类岔台左转，同时 3D 镜头采用不同观察角。转向证据要求事件前后 x/y 不变。
- 世界成功不能单独证明能力：首次相对转向须符合当前朝向，且只有一次原地转向。强提示后的同图成功不计独立迁移。

## 固定方案与反例

- 引导参考：`move ×2 → right → move ×2 → collect`；迁移参考：`move ×2 → left → move ×2 → collect`。
- 引导把右转换成左转，会真实走到北支路 `(4,1)`，在第 6 条空采失败；系统不会自动纠正路线。
- 额外保留朝西变式，连同旧运行器方向夹具覆盖 N/E/S/W。所有转向事件均验证位置不变。
