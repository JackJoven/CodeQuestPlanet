# 07 · 第 25 课：二维数据映射

Status: technical-acceptance-passed

开发依赖：第 23 课。范围：仅本课及必需的最小共用扩展。

## 学生应当学会什么

核心能力：**二维数据映射**。学生实际修改：编辑表格单元格，指定行列映射。

必须证明：不对称点、边界格、尺寸变化；world(x,y) 对应 table[y][x]，只改预期格。

## 关卡与操作

- 主任务：非正方形岛屿蓝图与同步地形。
- 机关作用：修改表格单元格立即改变对应落脚格。
- 原始坏方案：读取时交换 row/column。
- 迁移与防绕过：行列互换、边界格、尺寸变化；高度预设且可见，本课只考二维映射。

## 固定夹具与期望结果

1. 3 行×5 列 table[1][3] 对应 world(3,1)，区别于 (1,3)。
2. 左上角/最后一格/尺寸变化只改预期世界格；旧边界不能残留，表格、3D、俯视图、碰撞同源。

- 构造、修复、独立任务均可操作；修复先运行坏方案。缺槽才阻断，合法错误方案允许运行。
