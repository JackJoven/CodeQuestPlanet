# 05 · 第 22 课：长度与索引

Status: technical-acceptance-passed

开发依赖：第 21 课。范围：仅本课及必需的最小共用扩展。

## 学生应当学会什么

核心能力：**长度与索引**。学生实际修改：追加任务，读取长度，连接有效索引范围。

必须证明：执行前追加 0/1/2 项；空列表及最后有效索引；不漏新项、不越界。

## 关卡与操作

- 主任务：原物流群岛开放一个新码头。
- 机关作用：清单真正变长，旧长度会漏掉新任务。
- 原始坏方案：追加后仍用旧长度；访问 index == len。
- 迁移与防绕过：先追加后遍历；显示最后有效索引，地图变大不是唯一变化。

## 固定夹具与期望结果

1. 空表追加 0/1/2 项，再读 len；[A,B] 追加 C 后必须处理 C。
2. len=3 最后有效索引 2，访问 3 真实越界且不投递；空表 range(0) 安全退出。
