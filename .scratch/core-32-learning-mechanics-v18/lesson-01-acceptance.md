# 第 1 课验收：顺序执行

内容版本：`1.8-01.1`。日期：2026-09-20。未提交、未部署。

## 已实现

- 学生从空程序开始，在原“选择指令 / 我的程序”两列中点击追加、替换、删除、撤销与清空，亲自编排 `move()` 和 `collect()`。
- 两阶段为“排好执行顺序 / 距离变化迁移”。引导距离 3，独立迁移距离 5；距离 1 保留为固定边界夹具。
- 世界、生成 Python、逐步事件和能力证据来自同一学生程序。提前采集会在实际位置失败；抵达但未采集不成功；采集后的多余前进继续执行并使 Nova 离开目标格。
- 浮岛登陆台为 7×5 可行走平台，不是窄直线；目标标出真实格数。掌握需要一次引导成功和一份不同任务指纹、无强提示的迁移证据。

## 固定方案与反例

- 引导参考：`move ×3 → collect`；迁移参考：`move ×5 → collect`。直达任务受动作集与朝向约束，没有另一条等长语义方案；学生仍可自由构造和运行合法错误方案。
- 距离 1/3/5 均验证每张卡只产生一个对应事件。
- `collect → move` 在起点真实空采失败；`move ×3 → collect → move` 不吞尾部动作，最终离开目标并失败。
