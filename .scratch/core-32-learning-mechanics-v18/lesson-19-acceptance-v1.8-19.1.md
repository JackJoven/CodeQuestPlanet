日期：2026-09-17。内容版本：`1.8-19.1`；profile：v7。代码为当前工作区未提交变更，不是已部署版本。

**结论：技术闭环通过，可作为后续接入参考并开始小范围试教。真实学习效果、独立学习耗时及约 60 分钟标准课完整性尚未验证。**

## 1. 核心能力与实际操作

学生连接函数参数到循环次数，给同一函数的两次调用传入不同距离。输入槽、可查看的 Python、Skulpt 的实际函数调用和世界移动来自同一模型。学生可选择错误的固定数字或合法错误距离，并观察实际运行结果。

函数体的重复结构和前往码头入口的导航是明确脚手架；本样板不开放任意文本编辑，也不把选择参数槽等同于掌握所有函数写法。当前工具内的有效定义就是读取 distance；语义等价的任意 Python 写法不在本课 UI 的承诺范围。

## 2. 场景与实际结果

| 任务 | 输入 / 操作 | 实际结果 |
|---|---|---|
| 构造 | 同一函数接收 2、4，循环读取 distance | 移动 2、4 次，均正常结束，采集两颗宝石 |
| 合法错误调用 | A 填 3，实际距离 2 | 真正走 3 格后在错误位置采集失败；运行前不因答案错误而拦截 |
| 原始故障 | 函数固定重复 3，任务距离 2/4 | A 实参 2、循环值 3、移动 3；采集失败，有真实坏运行 |
| 第二种故障布局 | A 距离 4，函数仍固定 3 | 移动不足，真实失败；不只检测“超走一步”一种表象 |
| 修复 | 同图改为 distance | 2/4 或 4/2 实参被读取，修复前后程序版本不同、任务指纹相同 |
| 简短说明 | 对照 A 的实际修复记录，选择改前 3、改后 2 | 绑定前后运行 ID 校验；错误次数或普通标点不能替代解释 |
| 独立 T1 | 新入口方向，距离 1、5 | 成功保存一份独立证明，此时仍未掌握 |
| 独立 T0 | 再换图，距离 0、4 | 第一次调用不移动、正常结束，主程序继续采集；第二次移动 4 |
| 另一迁移 | 距离 5、0 | 自动测试通过第二调用为 0 的边界，避免只支持首调用零次 |
| 能力门 | 引导、修复、普通/零次迁移、有效说明齐备 | 显示已掌握，能力门 4/4 |

自动测试运行 guided/repair/challenge 各三个 variant 调用；guided 的相同语义不当作多份迁移。世界目标与参数能力分别计算，绕开真实参数读取不能靠终点状态获得能力证明。

## 3. 地形与新鲜感

主世界为两片宽码头、固定连接桥、两级高台和缺口；普通图与迁移改变入口方向、距离及高台表面。每格台阶仍是一次移动，不追加隐形次数。3D 显示实际高度、台阶、A/B 距离标记；俯视图显示层级、连接、起点和目标，数据来自同一 terrain。

样板只使用基础地形，不混入尚未教学的传送/时间规则。后续第 3/5/6/10/11/23/29/30 课按各自工单引入对应机关，不能把旋转这张码头图当成 32 课的地图多样性。
