## Question

第一次进入真实代码时，学生拥有多大编辑自由，Python 支持到什么范围，起始代码与原指令卡区域分别承担什么作用？

## Comments

### Resolution — 2026-08-11

从第 13 课起使用真实代码编辑器，但以可运行起始程序、代码模板和受控任务渐进开放，到第 16 课逐步撤掉脚手架。运行环境先支持课程所需的教学型 Python 子集。每课从包含一个明确问题或缺口的可运行程序开始，学生先观察再修改。原指令卡区域改为代码模板栏，只负责把片段插入学生源代码。
