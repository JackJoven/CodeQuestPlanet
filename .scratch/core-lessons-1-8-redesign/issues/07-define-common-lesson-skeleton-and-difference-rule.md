# 确定标准课共同骨架与差异原则

**Type:** `wayfinder:grilling`  
**Parent:** [让共同核心第 1–8 课真正可学](../MAP.md)  
**Status:** closed  
**Blocked by:** None

## Question

八节标准课应采用完全固定、适度统一还是完全独立的教学结构，以及怎样判定课程之间存在真实差异？

## Comments

### Resolution — 2026-08-10

采用一致的学习骨架，但允许各课根据目标改变活动形式。每课必须增加一种独特的核心思维活动或学习工具，不能只靠更换地图、剧情和美术制造差异。
