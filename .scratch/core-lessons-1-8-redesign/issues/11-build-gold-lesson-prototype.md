# 制作“调试侦探社”黄金标准课原型

**Type:** `wayfinder:prototype`  
**Parent:** [让共同核心第 1–8 课真正可学](../MAP.md)  
**Status:** open  
**Claimed by:** Codex

## Question

一个可运行、可观察完整学习状态的“调试侦探社”原型，是否能让学生在不依赖教师补充的情况下完成知识理解、迁移、调试和解释？

## Comments

### Prototype asset — 2026-08-10

- [“调试侦探社”学习状态临时原型](../../../signal-runner-node/debug-detective-logic-PROTOTYPE.html)
- 原型分支：逻辑 / 状态模型；单个自包含 HTML，刷新即清空，不连接账号、数据库或正式进度。
- 验证问题：资格补讲、固定调试方法、四类案件、分层提示、学习证据和等价任务重新评测，能否组成学生可独立操作的完整学习闭环。
- 已通过运行检查：无强提示迁移可进入“已掌握”；三级强提示只能进入“已完成”并要求等价案件 B；等价案件无强提示通过后才可掌握；跳过预测运行会被状态机阻止。
- 当前等待用户实际体验与 verdict；在确认前不关闭本票，不把原型视为生产实现。

### Student-facing prototype — 2026-08-10

- [学生从头到尾操作版](../../../signal-runner-node/debug-detective-student-PROTOTYPE.html)
- 将内部状态测试台改造成学生视角的一页完整课程：侦探资格检查、必要补讲、完整知识讲解、引导 / 半引导 / 独立案件、迁移能力门和学习证据总结。
- 学生必须先保存运行前预测，才能单步或连续运行；随后以“第一次偏离 → 根因 → 只改一处 → 重新验证 → 引证据解释”的顺序提交案件。
- 已检查五个案件的正确 / 错误程序结果，并跑通两条完整路径：无强提示直接掌握；三级强提示只能完成，换等价案件独立通过后才掌握。
- 本票继续保持 open，等待学生视角体验 verdict 后再决定是否关闭或迭代。

### Playgrounds simplification — 2026-08-10

- 用户 verdict：上一版学生流程过于复杂；资格检查、强制知识讲解、连续四案和逐项侦探笔记不适合作为学生进入课程后的默认路径。
- [Swift Playgrounds 式精简学生版](../../../signal-runner-node/debug-detective-playground-PROTOTYPE.html)
- 新默认路径：在一屏内读完任务与三个必要知识点，直接运行错误程序，点击一行替换一个指令，再次运行即可过关。
- “调试侦探社”保留为可选按钮，只提供一个三步示范；学生可以不进入，也可以随时返回原任务。
- 旧版完整状态原型继续保留，用作内部规则与证据模型参考，不再作为学生默认体验方向。
- 本票继续保持 open，等待精简版体验 verdict。

### Align with existing lesson workspace — 2026-08-10

- 用户 verdict：精简版页面结构和课程内容方向可接受；编程工作台需要对齐现有 `signal-runner-node/index.html`，并将 3D 任务固定在左侧。
- 精简原型已调整为左侧持久任务世界、右侧可滚动课程工作台；移动端也保持任务世界在编程区之前。
- 右侧按现有正式页的顺序组织：本关任务 / 知识讲解 → 选择指令 / 我的程序 → 生成代码 → 运行、单步、撤销、复位和清空 → 调试反馈。
- “调试侦探社”继续作为左侧任务区下方的可选辅助按钮，不再占用课程主标题或默认工作台。
- 已跑通直接运行、单步定位、替换指令、再次运行、清空 / 添加 / 撤销以及可选侦探社返回任务的路径；本票继续保持 open，等待新版体验 verdict。

### Playgrounds-style lesson copy — 2026-08-10

- 用户 verdict：总体双栏结构与编程工作台可接受；右侧顶部的本关任务和知识讲解仍需采用 Swift Playgrounds 的连续关卡说明方式，以增强游戏任务感。
- 已取消“本关任务 / 知识讲解”两个产品信息标签，将目标、必要规则和通关动作合并为“挑战 → 规则线索 → 完成挑战”的连续说明。
- `move()`、`turnLeft()`、`turnRight()` 使用关卡强调色，第一次不同作为唯一方法重点；可选侦探社说明保持弱化。
- 运行失败后完整关卡说明继续保留，只在末尾追加本次运行反馈，不再用错误状态替换知识讲解。
- 字体切换为 macOS / Windows 系统字体栈，更贴近 Playgrounds 的原生界面气质；本票继续保持 open，等待新版体验 verdict。

### Production lesson integration — 2026-08-10

- 用户确认最终结构后，已将精简体验接入正式 `signal-runner-node/index.html` 的共同核心第 6 课；另外 47 课继续使用原有课程呈现。
- 第 6 课进入时预装一段只错一处的七步程序；错误程序在空位置采集失败，学生把第 3 步 `turnLeft()` 原位替换为 `turnRight()` 后即可到达信标并过关。
- 右侧顶部已采用“挑战 → 必要规则 → 完成挑战”的 Playgrounds 式连续说明，左侧保持 3D 世界；运行反馈不会覆盖课程说明。
- “调试侦探社”作为左侧可选入口，展开后只展示预测、单步、找第一处不同、只改一处的四步方法和前三步对照，不阻断直接挑战路径。
- 编程器新增可复用的步骤选中 / 原位替换能力；到达指令上限时仍可选中已有步骤并替换，不需要先删除再追加。
- 已通过脚本语法、课程数据、HTML 挂钩、错误 / 正确路线模拟、差异格式和 Impeccable 类型 / 布局检测；本票继续保持 open，等待正式页面实际体验 verdict。

### Canonical lesson-order migration — 2026-08-10

- 随共同核心第 1–4 课按决策地图开始正式实现，“调试侦探社”已从临时的第 6 位迁移到正式第 4 课，避免课程表中同时存在两节调试课。
- 第 4 课当前错误程序为 `right → move → move → right → move → collect`；第 4 步是第一次偏离，错误在第 5 步撞墙时显现。把第 4 步替换为 `turnLeft()` 后即可到达信标并采集。
- 第 6、7 课的标题与课程内容顺序同步恢复为“多段任务顺序”和“我的第一条信标路线”；其专属学习工具留待对应课次实施。
