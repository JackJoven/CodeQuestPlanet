# Signal Runner Node

一个面向 12-14 岁学生的 3D 闯关式编程学习原型。

定位：

- 正式课程按 v1.3 的 48 节 Code Quest 创作型课程落地，已拆成 6 个阶段和 48 个可进入课次。
- 原 6 节作品节点保留为 Demo 轨道，用来展示交互、美术和综合玩法。
- 每节正式课都是一个任务包入口，学生通过编排程序让信标无人机完成任务。
- 知识线从序列、条件、循环、函数，推进到综合调试和验证。
- 主画面使用本地 vendored Three.js 渲染真实 3D 小岛，不依赖运行时 CDN 或构建工具。
- 低多边形模型、草地/沙地/水面贴图先用程序化资产生成，后续可替换为 Blender/GLB 美术资产。

打开方式：

可以直接用 Edge / Chrome 打开：

```text
signal-runner-node/index.html
```

页面使用本地全局版 Three.js，不依赖 CDN、构建工具或本地服务。

如果后续改回 ES Module、引入 `fetch()`、加载外部模型贴图，浏览器直接打开本地文件可能再次受限；那时可以使用本地服务。

如果后续需要本地服务，也可以手动运行：

```text
cd signal-runner-node
node server.mjs 4173
```

然后访问：

```text
http://127.0.0.1:4173
```

当前版本已经改成普通脚本加载，所以真实浏览器可以直接打开本地 `index.html`。

当前正式课程：

1. 课程入口先显示 6 个阶段。
2. 进入阶段后显示该阶段 8 节课。
3. 进入单课后打开对应 3D 地图、指令库、日志和作品卡。

课程内容数据在 `course-data.js`，界面和 3D 引擎共用 `app.js`。后续调整 UI 或 3D 表现时，不需要逐节修改课程页面。

保留 Demo 结构：

1. 指令序列：让无人机按顺序移动、采集、上传。
2. 路径调试：用转向和失败日志修正路线。
3. 传感器条件：遇到危险前自动开盾。
4. 循环压缩：用 repeat 减少重复移动。
5. 函数封装：定义 routeA，再在主程序里调用。
6. 综合作品：采集三座信标并上传，形成完整作品卡。

这是当前主项目，不依赖已归档的 L1 状态课或 L2 AI 验证课。
