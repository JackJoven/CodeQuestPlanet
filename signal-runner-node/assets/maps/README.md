# CodeQuestPlanet Map Assets

This folder contains the generated visual map set for the six-stage Signal Runner course.

- `learning-world-overview`: top-level six-world navigation map.
- `stage-01-beacon-departure`: basic actions and route planning.
- `stage-02-energy-rescue`: loops, conditions, hazards, and energy state.
- `stage-03-function-toolbox`: variables, functions, parameters, and lists.
- `stage-04-star-map-data-station`: data modeling and multi-object cooperation.
- `stage-05-maze-pathfinding`: search, DFS, BFS, path reconstruction, and route cost.
- `stage-06-strategy-launch-summit`: strategy, testing, and original project publishing.

Use the WebP files in webpage layouts and keep the PNG files as high-quality source assets.
Stage maps intentionally contain eight large route nodes so HTML buttons can be positioned above the artwork.

Generated with the built-in image generation workflow from project visual references. No UI text, logos, or labels are baked into the artwork.
