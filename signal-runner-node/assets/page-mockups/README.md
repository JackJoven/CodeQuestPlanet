# CodeQuestPlanet Page Mockups

Full-page visual mockups for the learning-world navigation hierarchy:

- `learning-world-overview-page`: top-level six-stage overview.
- `stage-01-page` through `stage-06-page`: full stage pages with an embedded map, progress rail, current task, abilities, stage work, and eight-lesson navigation track.

PNG files are the high-quality source images. WebP files are optimized for quick browser preview.

These are visual direction images rather than production UI screenshots. In the implemented website, navigation labels, lesson names, progress, locks, and buttons should be rendered as accessible HTML above the map artwork, not baked into raster images.
