# v0.5 第一二关自学引导增强 PRD

## 背景

上一版第 1、2 关存在一个明显问题：学生只要点击“修复规则”，游戏就能继续运行，容易变成“点按钮过关”，而不是理解编程概念。

本版目标是把前两关改成适合无老师或少老师场景的自学式关卡。学生需要先观察问题，再形成猜想，最后分步修复规则。

## 设计原则

1. 不直接给答案，先制造可观察的问题。
2. 不一次性修好，拆成 2-3 个小实验。
3. 每一步都要有可见反馈，比如坐标变化、变量变化、屏幕分数变化。
4. 过关不是“点了按钮”，而是能用自己的话解释规则链路。

## 第 1 关：控制诊断场

核心概念：事件、方向判断、坐标、速度。

学生路径：

1. 按两个不同方向键，确认系统能听见输入事件，但角色不动。
2. 只连接左右移动，观察 x 坐标变化。
3. 再连接上下/跳跃，观察 y 坐标变化。
4. 最后校准 speed，完成目标并复盘“输入 -> 坐标 -> 移动”。

自学出口：

学生能解释“按键只是事件，坐标变化才让角色移动”，并能说出 x、y、speed 分别影响什么。

## 第 2 关：分数侦探局

核心概念：变量、UI 同步、状态防重复。

学生路径：

1. 先收集物品，确认“碰到了但不计分”。
2. 连接 score 变量，观察变量 score 变化。
3. 同步屏幕 UI，观察屏幕分数和变量 score 是否一致。
4. 启用防重复计分，收集全部目标并复盘变量链路。

自学出口：

学生能解释“score 是游戏记忆，屏幕分数只是显示”，并知道为什么要判断物品是否已经被收集。

## 页面改动

新增“自学任务单”，包含：

1. 目标：这一关到底要学会什么。
2. 观察：先看哪个现象。
3. 实验：每次只修哪一条规则。
4. 出口：怎么判断自己真的学会了。

## 验收标准

1. 第 1 关不能再一键完成控制修复。
2. 第 2 关不能再一键完成计分修复。
3. 学生在没有老师讲解的情况下，能根据页面提示知道下一步做什么。
4. 页面必须显示“变量 score”和“屏幕分数”的差异，帮助理解变量和 UI 的关系。
