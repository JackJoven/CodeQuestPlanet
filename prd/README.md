# PRD 目录

这里用于沉淀 AI 游戏编程平台的产品需求文档，后续每次重要方向调整都新增一个版本，避免覆盖历史思路。

## 版本索引

| 版本 | 文件 | 说明 |
|---|---|---|
| v0.1 | `v0.1-ai-game-programming-platform.md` | 第一版产品方向 PRD：学生自驱、AI 伴学、自研平台、游戏规则编程。 |
| v0.2 | `v0.2-six-lesson-mvp-phaser.md` | 第二版 6 课 MVP PRD：明确 Phaser 技术栈、课程结构、前后端边界。 |
| v0.3 | `v0.3-学习效果评价与作品展示体系.md` | 第三版评价体系 PRD：明确阶段评价、最终评价、家长报告和作品展示。 |
| v0.4 | `v0.4-第一关第二关游戏重设计.md` | 第四版关卡设计 PRD：基于评价体系重设计第 1 关和第 2 关。 |

## 命名约定

- `v0.x`：探索期和 MVP 版本。
- `v1.x`：完成真实小规模交付后的正式课程/平台版本。
- 从 `v0.3` 开始，新增 PRD 文档统一使用中文命名。
- 每个版本尽量保留当时的关键假设、非目标和取舍理由。
